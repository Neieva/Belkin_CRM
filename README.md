# Belkin CRM

Простая CRM для маркетингового агентства: проекты клиентов, ответственные по процессам,
задачи (канбан), график предоплат, документы и договоры, заметки.

## Запуск

```bash
node server.js        # http://localhost:3000
```

Нужен только Node.js 18+, зависимости не требуются.
Данные хранятся в `data/db.json` (ежедневная копия `data/db.backup-ГГГГ-ММ-ДД.json`),
загруженные файлы — в `data/files/`. Папка `data/` не попадает в git.
При первом запуске создаются демо-проекты; удалить их можно кнопкой слева внизу.

Переменные окружения: `PORT` (по умолчанию 3000), `DATA_DIR`.

> Приложение рассчитано на одного пользователя и не имеет авторизации —
> не выставляйте его в открытый интернет без защиты.
